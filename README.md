# Calculator

Простой консольный калькулятор на Python.

## Возможности

Калькулятор поддерживает четыре основные операции:

* сложение `+`
* вычитание `-`
* умножение `*`
* деление `/`

## Структура проекта

```text
calculator/
├── main.py
├── operations.py
└── README.md
```

### `main.py`

Основной файл программы. Отвечает за взаимодействие с пользователем и выбор операции.

### `operations.py`

Вспомогательный модуль с функциями математических операций:

* `add()`
* `subtract()`
* `multiply()`
* `divide()`

## Запуск

Убедитесь, что установлен Python.

Запустите программу из директории проекта:

```bash
python main.py
```

## Пример использования

```text
Введите первое число: 10
Введите операцию (+, -, *, /): *
Введите второе число: 5
Результат: 50.0
```

## Обработка ошибок

При попытке деления на ноль программа выведет сообщение:

```text
Ошибка: На ноль делить нельзя
```

При вводе неизвестной операции:

```text
Неизвестная операция
```

## Требования

* Python 3.x
* Дополнительные библиотеки не требуются.
